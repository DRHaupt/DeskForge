# Dekaiah Haupt Technical logos

Three options (a: DH monogram, b: circuit D, c: shield). For each:

- `icon-X.svg` / `icon-X.png` (512×512): the symbol, for `branding.logo` and `branding.favicon`
- `email-logo-X.png` (756×144): symbol and name, for `branding.emailLogo`
- `logo-X.svg`: symbol and name as vector art, for print or other uses

Colours: blue `#2563eb`, navy `#0f2a4a`, grey `#5b6b80`. Fonts: Manrope 700 and Inter 600 (converted to outlines).
