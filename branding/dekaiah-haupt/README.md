# Dekaiah Haupt Technical logos

Three options (a: DH monogram, b: circuit D, c: shield). For each:

- `icon-X.svg` / `icon-X.png` (512×512): the symbol, for `branding.logo` and `branding.favicon`
- `email-logo-X.png` (756×144): symbol and name, for `branding.emailLogo`
- `logo-X.svg`: symbol and name as vector art, for print or other uses

Colours: blue `#2563eb`, navy `#0f2a4a`, grey `#5b6b80`. Fonts: Manrope 700 and Inter 600 (converted to outlines).

## Interlocked DH (chosen design)

- `dh-icon.svg` / `dh-icon.png` (512×512): white D and pale-blue H on a navy tile, for `branding.logo` and `branding.favicon`
- `dh-email-logo.png` (756×144): the tile and name, for `branding.emailLogo`
- `dh-logo.svg`: the tile and name as vector art; `dh-logo-plain.svg`: without the tile
- `dh-mark.svg` (navy and blue, for light backgrounds) and `dh-mark-white.svg` (for dark backgrounds): the mark on its own

Colours: navy `#0f2a4a`, blue `#2563eb`, pale blue `#9cc0ff`, grey `#5b6b80`.
